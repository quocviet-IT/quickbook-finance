What a Chart of accounts file needs
Account code
Account name
Type
Description
Opening balance
Blue columns are required. One file, every account — each row is one record, so a second file is only needed for a second kind of data.
QuickBooks: Reports → Account List. Wave: Accounting → Chart of Accounts → Export.
Before you start
  • An account code that already exists is left exactly as it is and reported. The same number means different things in two charts, so nothing here overwrites an account you already rely on.
Holding a report rather than a data file?
A Profit and Loss, a Balance Sheet or a bank statement you only want to keep can be saved under Reports → Saved Reports. Importing posts; saving does not affect a balance at all.
